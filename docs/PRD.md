# 宠物健康日历 PRD

版本：V0.1  
日期：2026-04-29

## 1. 产品定位

面向养猫/养狗用户的疫苗、驱虫、体检提醒与记录小程序。第一版只解决一件事：让用户知道下一次该做什么，并在完成后留下记录。

## 2. MVP 目标

- 用户 1 分钟内完成第一只宠物建档。
- 用户建档后能看到未来健康待办。
- 用户能标记一次完成，并自动生成下一次提醒。
- 验证用户是否愿意订阅提醒、二次打开和分享健康卡片。

## 3. 目标用户

- 20-35 岁养猫/养狗新手。
- 习惯在小红书查养宠攻略，在微信里接收日程提醒。
- 经常忘记疫苗、驱虫、体检时间。

## 4. 核心功能

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| 添加宠物 | P0 | 类型、名字、生日/年龄、历史日期 |
| 健康日历 | P0 | 展示最近待办、逾期事项、本月事项 |
| 完成记录 | P0 | 记录完成日期、备注、下次提醒 |
| 自动生成下次提醒 | P0 | 根据周期生成下一次事项 |
| 历史记录 | P0 | 查看疫苗、驱虫、体检记录 |
| 分享卡片 | P1 | 生成宠物健康状态卡片 |
| 多宠管理 | P1 | 切换与管理多只宠物 |

## 5. 不做范围

- 不做 AI 问诊。
- 不做药品剂量推荐。
- 不做宠物社区。
- 不做医院比价。
- 不做电商闭环。

## 6. 页面结构

- 首页：健康日历
- 添加宠物页
- 待办详情页
- 完成记录页
- 历史记录页
- 我的宠物页

## 7. 提醒规则

默认模板可编辑：

- 体内驱虫：90 天
- 体外驱虫：30 天
- 体检：365 天
- 疫苗：用户手动设置下一次日期

所有文案必须说明：仅作日程提醒和历史记录，具体方案以宠物医生建议为准。

## 8. 核心指标

- 添加宠物完成率 > 60%
- 提醒订阅率 > 35%
- 首次记录完成率 > 20%
- D7 留存 > 12%

## 9. 变现模型

MVP 优先验证广告，不阻断核心流程。后续考虑无广告、多宠、高级卡片、家庭共享等增值能力。

## 10. 冷启动

小红书内容关键词：

- 新手养猫疫苗时间表
- 猫咪驱虫多久一次
- 狗狗疫苗驱虫时间表
- 猫三联什么时候打

小程序搜索命名优先包含关键词，建议名称：宠物疫苗驱虫提醒。
