# PetHealthCalendar

宠物健康日历微信小程序 MVP。

## MVP 范围

- 添加宠物档案
- 自动生成疫苗、驱虫、体检待办
- 首页查看最近待办与逾期提醒
- 标记完成并生成下一次提醒
- 查看历史记录

## 使用方式

1. 用微信开发者工具导入本目录。
2. AppID 可先选择测试号。
3. 编译后从首页开始体验。

## 当前状态

这是第一版原生小程序骨架，数据暂存在本地缓存，适合验证 MVP 流程。

## UI/UX

- 设计系统见 `design-system/MASTER.md`。
- 页面已按 `$ui-ux-pro-max` 核心规则补充移动端触控尺寸、表单标签、辅助说明、错误反馈、按压态、空状态和状态标签。
- 仍需在微信开发者工具中做小屏、横屏、动态字号和真机触控验证。
